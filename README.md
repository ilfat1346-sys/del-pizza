# Del'pizza Баймак — демо-сайт доставки

Тёмная («светло-тёмная» тема) витрина для заведения **Del'pizza** (Баймак, пр-т Салавата Юлаева, 28а):
каталог из 42 позиций (пицца, комбо-сеты, роллы и суши, шаурма и донеры, бургеры, закуски, десерты,
напитки, соусы), корзина, оформление заказа (доставка/самовывоз), промокод `DEL15`,
**тестовая онлайн-оплата (СБП/карта — демонстрация, деньги не списываются)**.

## Как открыть

Двойной клик по `index.html` — сайт работает полностью офлайн (данные в `js/data.js`, фото в `img/`).
Либо локальный сервер: `python -m http.server 8000` → http://localhost:8000

## Тестовая оплата

1. Добавьте товары в корзину → «Перейти к оформлению».
2. Выберите **«Онлайн-оплата · тестовый режим»** — рядом появится пометка
   «🧪 Это тестовый режим оплаты: настоящие деньги не списываются».
3. «Оформить заказ» → «Оплатить» → экран «Заказ принят», в тексте заказа метка «оплата: онлайн (тестовый режим)».

Боевой режим: подключить СБП/ЮKassa/Эвотор к обработчику оплаты в `js/app.js` (функции `payGo`/`finalizeOrder`).

## Файлы

| Путь | Что |
|---|---|
| `index.html`, `css/style.css`, `js/app.js` | вёрстка, стиль, логика |
| `js/data.js` | меню и цены — **демонстрационные** |
| `tools/fetch_images.py` | загрузка свободных фото (Wikimedia/Openverse) |
| `tools/selftest.py` | автотест в headless Chrome (каталог, корзина, промокод, оплата, битые фото) |
| `shots/` | скриншоты |

## Куда попадает заказ

- сохраняется в `localStorage` браузера (история заказов);
- кнопка «Скопировать заказ» — текст можно сразу вставить в WhatsApp/VK.

При желании подключается прямой приём заказов в админку (AdminHub — как в проекте «Бай-Тандыр»).

> ⚠️ Цены, состав меню и фото — демонстрационные. Перед показом клиенту/публикацией заменить
> на реальные данные заведения.
